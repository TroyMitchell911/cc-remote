# cc-remote v5.3.3

## 中文

修复 Claude 在原生终端与 cc-remote 之间切换时的状态显示、侧边聊天重连，以及回退后的界面和历史同步。

- 模型与思考强度选择对齐原生账号设置；从 CLI 恢复会话后，Remote 正确识别会话持有者。终端正在处理、结束或被 Ctrl+C 打断时，界面同步对应状态。
- 修复侧边聊天修改思考强度后重连时重复使用 fork 会话 ID 的问题，保留已经确认接收的消息，不自动重发。
- 回退成功后关闭弹窗；CLI 后续修改设置或发送新消息时，已回退的旧问答不再重新出现。
- 修复 Claude 首次回复前切换引擎，再切回来时，同一条用户消息偶尔显示两次的问题。
- 流式输出时可用键盘向上离开底部，到底后恢复跟随；Linux 桌面端的引擎切换快捷键调整为 Alt+1/2/3。

### 升级

通信协议保持 **v85**，Claude Agent SDK 保持 **0.2.174**。从 v5.3.2 升级无需协议或 SDK 迁移。更新 Relay 和各台 Wrapper 后，刷新 Web/PWA 或重新打开 Desktop。已有 Claude 历史缓存会按需重建，原生会话记录和图片等资源保留。

```sh
cc-remote update --check --version 5.3.3
cc-remote update --version 5.3.3
```

模型和强度遵循原生 CLI 的账号默认值规则，不新增官方尚未提供的逐会话持久化能力。普通 Wrapper 更新不会重启独立 Claude 会话服务；仍在 Wrapper 进程内运行的侧边聊天和排队消息需先完成。

发布包含六个平台的 Relay/Wrapper 包、`install.sh` 和 `SHA256SUMS`，由 GitHub Actions 完成回归、平台导入检查和 attestation。没有新的 Desktop 或移动端安装包。

## English

Fix Claude session state across native CLI and Remote use, side-chat reconnects, and UI/history synchronization after rewind.

- Align model and effort choices with native account settings and track ownership when a CLI resumes another session. Mirror terminal activity, completion and Ctrl+C interruption.
- Avoid reusing a fork reservation when reconnecting a side chat after an effort change. Preserve accepted inputs without automatically resubmitting them.
- Close successful rewind dialogs and keep removed messages out of the active history branch when the CLI changes settings or sends another prompt.
- Prevent a new Claude prompt appearing twice when switching engines before its first response.
- Allow keyboard scrolling away from streaming output and resume following at the bottom. Linux desktop engine shortcuts become Alt+1/2/3.

### Upgrade

Wire protocol remains **v85** and Claude Agent SDK remains **0.2.174**. Upgrading from v5.3.2 needs no protocol or SDK migration. Update the Relay and each Wrapper, then reload Web/PWA or reopen Desktop. Derived Claude history caches rebuild as needed; native transcripts and binary assets are preserved.

```sh
cc-remote update --check --version 5.3.3
cc-remote update --version 5.3.3
```

Model and effort follow native account-default semantics; this release does not add per-conversation persistence absent from the native CLI. Ordinary Wrapper updates preserve the independent Claude session service. In-process side chats and queued messages must finish before activation.

The release includes six platform-specific Relay/Wrapper bundles, `install.sh` and `SHA256SUMS`, with GitHub Actions regression tests, platform import checks and attestation. It includes no new Desktop or mobile installer.
