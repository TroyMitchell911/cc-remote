# cc-remote v5.1.0

## 中文

v5.1.0 新增按账号开启的额度查询与月额度显示，改进跨会话发送工具和手机端布局。通信协议从 **v82 升到 v83**；Claude Agent SDK 保持 **0.2.157**。

### 功能与修复

- 额度栏支持 5 小时、周、月的任意组合，只显示实际返回的周期。月额度遵循上游订阅周期和重置时间，不假定一个月固定为 30 天；上下文占用仍单独显示。
- Claude 账号的主动额度查询默认关闭，原生 `RateLimitEvent` 和缓存同步继续工作。需要主动查询的账号在本机配置 `usage_query_enabled: true`，并绑定只读额度 helper；兼容 Anthropic API 的网关可由外部 helper 提供统一数据，无需按账号别名或厂商添加内置适配。
- 额度数据按账号隔离，处理独立过期、显式清除和稀疏更新。新收到的原生事件优先于较早发起的查询；失败时保留仍有效的缓存，并显示查询状态。查询额度不会发送模型消息或尝试 SDK 对话接口。
- 跨会话消息的投递状态、接收会话、账号和可复制内容显示在对应的 MCP 发送工具内，随着后续工作保持原有顺序。原始参数和输出默认折叠，接收端的会话来源和跳转保留。
- 修复手机端长哈希、行内文本溢出和权限名称显示不全的问题；一到三行额度保持紧凑布局。

### 升级与配置

**v83 与 v82 不互通。** 安排全部设备的维护窗口，等待进程内 Claude、临时侧聊和排队任务结束。按[部署流程](https://github.com/muggle-stack/cc-remote/blob/v5.1.0/deploy/README.md)先准备并验证全部安装包，停止不兼容的旧 Wrapper，再切换 Relay/Web 和所有 Wrapper，最后刷新 Web/PWA。

已登记的 Release 安装可在独立终端检查并升级：

```sh
cc-remote update --check --version 5.1.0
cc-remote update --version 5.1.0 --allow-protocol-change
```

更新器使用现有 SSH 管理权限验证并按需升级 Relay/Web，然后更新当前设备。其余设备仍需逐一更新；上述参数不会自动协调所有设备，失败回滚由各安装事务处理。普通 Wrapper 更新保留独立 Claude 服务及原生 Codex daemon 的生命周期。

**已有额度 helper 的账号也需显式开启主动查询。** 在该账号配置中设置 `usage_query_enabled: true`，随 Wrapper 下次启动生效。未开启的账号继续接收原生额度事件；缺少 helper 时提示未配置，不猜测接口。配置和数据格式见[额度指南](https://github.com/muggle-stack/cc-remote/blob/v5.1.0/docs/claude-usage.md)。账号凭据、网关实现及 helper 配置保留在本机。

发布包含六个 Relay/Wrapper 平台包、`install.sh` 和 `SHA256SUMS`，由 GitHub Actions 执行回归、平台安装包导入检查及 attestation。没有新的 Desktop 或移动端安装包；已从 Relay 加载页面的客户端刷新即可获取新界面。发布本身不切换线上服务，自动化回归不调用真实模型。

## English

v5.1.0 adds opt-in account usage queries and monthly quota display, and improves
cross-session send tools and mobile layout. Wire protocol advances from **v82
to v83**. Claude Agent SDK remains pinned to **0.2.157**.

### Features and fixes

- Display any supplied combination of 5-hour, weekly and monthly quotas. A
  month follows the upstream subscription cycle and reset time, with no fixed
  30-day assumption. Context usage remains a separate control.
- Default active Claude usage queries to off while preserving native
  `RateLimitEvent` and cache synchronization. An opted-in account sets
  `usage_query_enabled: true` locally and binds a read-only usage helper.
  External helpers can normalize an Anthropic-compatible gateway's quota
  response without account-alias or provider-specific built-in adapters.
- Keep observations account-scoped, expire windows independently, and support
  explicit clearing and sparse updates. Newer native events win over older
  in-flight reads; failures preserve valid cached data with a query-state
  notice. Usage reads never send a model prompt or use an SDK conversation API.
- Keep delivery status, recipient, account and copyable message content inside
  the originating MCP send tool as later work continues. Collapse raw parameters
  and output, and preserve receiving-session source links and navigation.
- Wrap long inline text and hashes on mobile, show complete permission labels,
  and fit one to three compact quota rows.

### Upgrade and configuration

**Protocol v83 cannot communicate with v82.** Schedule a maintenance window for
all devices and drain in-process Claude/BTW work and queued tasks. Follow the
[deployment procedure](https://github.com/muggle-stack/cc-remote/blob/v5.1.0/deploy/README.md):
stage and validate all bundles, stop incompatible old Wrappers, activate
Relay/Web and every Wrapper, then reload Web/PWA clients.

From an independent terminal, registered Release installations can run
`cc-remote update --check --version 5.1.0`, followed by
`cc-remote update --version 5.1.0 --allow-protocol-change`.
The updater uses existing SSH administration access to verify/update Relay/Web
before this device. Other devices still need individual updates; the flag does
not coordinate every device automatically. Rollback is per installation.
Ordinary Wrapper updates preserve independent Claude service and native Codex
daemon lifetimes.

**Existing usage-helper users must explicitly opt in too.** Set
`usage_query_enabled: true` for the intended account; it takes effect when the
Wrapper next starts. Disabled accounts retain native quota events. A missing
helper is reported as unconfigured, with no inferred endpoint fallback. See the
[usage contract](https://github.com/muggle-stack/cc-remote/blob/v5.1.0/docs/claude-usage.md).
Credentials, gateway implementations and helper configuration remain local.

The release includes six Relay/Wrapper bundles, `install.sh` and `SHA256SUMS`,
with GitHub Actions regression tests, native package import checks and artifact
attestation. It includes no new Desktop or mobile installer; clients already
loading their UI from Relay can refresh for the new interface. Publishing does
not deploy services, and automated regression tests do not call a live model.
