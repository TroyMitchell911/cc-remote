# cc-remote v5.3.4

## 中文

修复会话误隐藏、历史合并、缓存竞争和阅读位置跳动，并简化输入区、状态提示与手机会话列表。

- 支持 Codex 原生压缩历史，保留会话、置顶、模型和思考强度，压缩前后消息 ID 保持一致。解压放在后台线程，避免阻塞其他会话输出和停止操作。
- 原生 Codex App 恢复压缩会话后，正确识别运行状态与只读控制；子代理详情和旧版代理卡片能读取压缩记录，显示正文、工具过程及完成状态，并排除继承的父会话内容。
- 修复 Claude 已完成答案短暂消失和后台回复顺序错乱；失效会话仍可取消置顶。
- 缩短历史缓存写事务，避免并发读取时的锁竞争和旧扫描覆盖新索引。
- 自动收起过程详情时保留正在阅读的正文位置；修复已经到底却仍显示置底按钮、键盘滚动受阻，以及切换输入法时正文出现焦点横线的问题。
- 主聊与侧聊移除引导／排队切换按钮。运行中，Enter 或点击发送用于补充当前任务；桌面端 Tab 将本次输入排队，输入法和补全操作保持优先。后台任务弹层移除重复标题及关闭按钮，可点击外部或按 Escape 收起。
- 状态提示收进 idle 左侧，支持展开查看、关闭和成功后自动消失。外观提供紧凑／舒展会话排布，多账号紧凑列表以框外圆点区分账号，悬浮标题查看完整目录。
- 手机长按放大会话并稳定显示操作菜单，点击外部先收起菜单，仅当前会话常显三个点；同时修正手机引擎名称、路径浮层配色和中文标点旁的加粗链接渲染。

### 升级

通信协议保持 **v85**，Claude Agent SDK 保持 **0.2.174**。从 v5.3.3 升级无需协议或 SDK 迁移。更新 Relay 和各台 Wrapper 后，刷新 Web/PWA 或重新打开 Desktop。历史缓存可按需重建，原生会话记录保持不变。

```sh
cc-remote update --check --version 5.3.4
cc-remote update --version 5.3.4
```

普通 Wrapper 更新不会重启独立 Claude 会话服务；仍在 Wrapper 进程内运行的侧边聊天和排队消息需先完成。

发布包含六个平台的 Relay/Wrapper 包、`install.sh` 和 `SHA256SUMS`，由 GitHub Actions 完成回归、平台导入检查和 attestation。没有新的 Desktop 或移动端安装包。

## English

Fix hidden sessions, history merging, cache contention and reading-position jumps, and simplify chat controls, status feedback and the mobile session list.

- Read native compressed Codex histories while preserving sessions, pins, model/effort settings and stable message IDs. Decode in background threads so other sessions and Stop commands remain responsive.
- Restore native activity and read-only control when the Codex App resumes a compressed thread. Read compressed subagent details and legacy cards with their text, tool activity and completion status, excluding inherited parent context.
- Prevent completed Claude answers from briefly disappearing and background replies from appearing out of order. Allow stale sessions to be unpinned.
- Keep history scans outside cache write transactions and reject stale index updates, reducing contention during concurrent reads.
- Preserve the visible text when process details collapse after a response. Correct bottom-button and keyboard-scroll boundaries, and remove the transcript focus line triggered by input-method switching.
- Remove the steer/queue switch from main and side chats. During an active turn, Enter or Send adds input to the current task; desktop Tab queues that input, with composition and completion taking priority. Background-task panels close on outside click or Escape without a duplicate heading or close button.
- Place expandable, dismissible status feedback beside idle, with automatic dismissal for success. Offer compact and comfortable session layouts, account dots outside compact rows, and full directory paths on title hover.
- Enlarge mobile rows on long press, keep menus stable, dismiss the menu before the sidebar on outside taps, and show persistent menu buttons only for the selected session. Correct mobile engine labels, path-tooltip contrast and bold links beside Chinese punctuation.

### Upgrade

Wire protocol remains **v85** and Claude Agent SDK remains **0.2.174**. Upgrading from v5.3.3 needs no protocol or SDK migration. Update the Relay and each Wrapper, then reload Web/PWA or reopen Desktop. Derived history caches rebuild as needed; native transcripts remain unchanged.

```sh
cc-remote update --check --version 5.3.4
cc-remote update --version 5.3.4
```

Ordinary Wrapper updates preserve the independent Claude session service. In-process side chats and queued messages must finish before activation.

The release includes six platform-specific Relay/Wrapper bundles, `install.sh` and `SHA256SUMS`, with GitHub Actions regression tests, platform import checks and attestation. It includes no new Desktop or mobile installer.
