# cc-remote v5.0.1

## 中文

v5.0.1 修复旧版 macOS Desktop 的界面版本兼容和 Claude 后台继续处理的历史展示，并更新双语 README 与功能截图。通信协议保持 **v82**，Claude Agent SDK 保持 **0.2.157**。

### 修复与文档

- 旧 Desktop 内置页面可能在 Relay 升级后反复提示“等待服务端完成部署”。新增兼容修复工具，为已知外壳生成独立签名副本，从配置的 Relay 加载界面；保留连接设置、登录 Cookie 和原生集成。普通 Web 更新可通过刷新或重开修复后的 Desktop 获取。
- Claude 收到后台任务通知后继续回答时，保留独立的续答身份、时间顺序和结束状态。成功续答不再继承上一段的失败状态，也不会被合并到原回答的错误位置；原始上游错误仍然保留。
- 历史缓存从 schema 50 升到 51 时，仅重建派生的 Claude 历史页与轮次详情，保留原生会话记录、索引和二进制资源。
- 双语 README 补齐 Claude、Codex、DSH 功能对照及限制，加入 13 张使用隔离演示数据截取的 Desktop 图片，覆盖会话、子代理、终端、自动化、产物、预览和外观。

### 升级与客户端

从 v5.0.0 更新不涉及通信协议变化。已登记的 Release 安装可在独立终端运行：

```sh
cc-remote update --check --version 5.0.1
cc-remote update --version 5.0.1
```

更新器验证并按需升级 Relay/Web，再更新当前设备的 Wrapper；其他设备仍需逐一更新。更新后刷新 Web/PWA。普通 Wrapper 更新保留独立 Claude 服务及原生 Codex daemon 的生命周期。

从 v4.x 升级仍需按 [v5.0.0 的协议升级说明](https://github.com/muggle-stack/cc-remote/blob/v5.0.1/docs/releases/v5.0.0.md)协调全部设备。

Desktop 修复是单独的本机操作，详见 [Desktop 兼容指南](https://github.com/muggle-stack/cc-remote/blob/v5.0.1/docs/desktop.md)。`cc-remote update` 不自动改写 Desktop 应用。本次没有新的公证 Desktop 或移动端安装包；Electron 和原生桥接变化仍可能需要单独更新外壳，重新打开应用不能解决 Relay/Wrapper 协议不一致。

发布包含六个 Relay/Wrapper 平台包、`install.sh` 和 `SHA256SUMS`。GitHub Actions 运行 Web 构建、pytest、各平台安装包导入检查并生成 attestation。发布本身不切换线上服务，这些自动化检查不调用真实模型。

## English

v5.0.1 repairs legacy macOS Desktop compatibility and Claude background
continuation history, and refreshes both READMEs and the feature gallery.
Wire protocol remains **v82** and Claude Agent SDK remains **0.2.157**.

### Fixes and documentation

- Add a compatibility helper for the known legacy Desktop shell, which could
  repeatedly load its outdated bundled page after a Relay upgrade. Stage a
  separately signed copy that loads the configured Relay UI while preserving
  settings, login cookies and native integrations. Refreshing or reopening the
  repaired shell picks up ordinary Web updates.
- Preserve Claude continuation identity, timeline order and terminal ownership
  across live events, refreshed history and browser caches. Successful replies
  after background notifications no longer inherit an earlier failure or appear
  in the wrong answer; original provider errors remain visible.
- Advance the history cache from schema 50 to 51, rebuilding only derived
  Claude pages and turn details while retaining native transcripts, indexes
  and binary assets.
- Document Claude/Codex/DSH capabilities and limitations with 13 Desktop
  screenshots captured using isolated demonstration data, covering sessions,
  subagents, terminals, automation, artifacts, previews and appearance.

### Upgrade and clients

Upgrading from v5.0.0 does not change the wire protocol. From an independent
terminal, registered Release installations can run `cc-remote update --check
--version 5.0.1`, followed by `cc-remote update --version 5.0.1`.
The updater verifies and updates Relay/Web as needed, then the current Wrapper;
other devices still need individual updates. Reload Web/PWA afterward.
Ordinary Wrapper updates preserve the independent Claude service and native
Codex daemon lifetimes. Upgrades from v4.x still require the coordinated
[v5.0.0 protocol migration](https://github.com/muggle-stack/cc-remote/blob/v5.0.1/docs/releases/v5.0.0.md).

The [Desktop repair](https://github.com/muggle-stack/cc-remote/blob/v5.0.1/docs/desktop.md)
is a separate local operation; `cc-remote update` does not rewrite the app.
No new notarized Desktop or mobile installer is included. Electron/native bridge
changes may still require shell updates, and reopening cannot resolve a
Relay/Wrapper protocol mismatch.

The release contains six Relay/Wrapper bundles, `install.sh` and `SHA256SUMS`.
GitHub Actions runs the Web build, pytest, native package import checks and
artifact attestation. Publishing does not deploy services, and these automated
checks do not send live model prompts.
