# cc-remote v5.3.6

## 中文

改善文件路径提示和图片文件预览的使用体验。

- 文件路径提示在鼠标停留 500 毫秒后显示，避免鼠标路过时遮住正文；键盘聚焦和点击打开文件仍即时响应。
- 居中和侧边预览中的长图默认按面板宽度从顶部显示，方便直接阅读；仍可缩小查看整张图片。
- 修复图片打开时先显示完整小图、再瞬间拉宽的闪动，第一次显示即使用正确的尺寸和位置。
- 提高触控板双指缩放的响应幅度，保留触屏缩放和 Safari 手势去重处理。

通信协议保持 **v85**，Claude Agent SDK 保持 **0.2.174**。从 v5.3.5 升级无需协议或 SDK 迁移。更新 Relay 和各台 Wrapper 后刷新 Web/PWA 或重新打开 Desktop。

```sh
cc-remote update --check --version 5.3.6
cc-remote update --version 5.3.6
```

普通 Wrapper 更新保留独立 Claude 会话服务；仍在 Wrapper 内运行的侧聊及排队消息需先完成。发布包含六个平台的 Relay/Wrapper 包、`install.sh` 和 `SHA256SUMS`，没有新的 Desktop 或移动端安装包。

## English

Improve file path tooltips and image file previews.

- Show file path tooltips after 500 ms of hover to avoid covering text as the pointer passes over a link; keyboard focus and file opening remain immediate.
- Open tall images at panel width from the top in centered and docked previews, while retaining zoom-out to see the entire image.
- Prevent the initial flash of a smaller image before width fitting; the first visible frame uses the correct size and position.
- Increase trackpad pinch response while preserving touchscreen zoom and protection against duplicate Safari gesture streams.

Wire protocol remains **v85** and Claude Agent SDK remains **0.2.174**. Upgrading from v5.3.5 needs no protocol or SDK migration. Update the Relay and each Wrapper, then reload Web/PWA or reopen Desktop.

```sh
cc-remote update --check --version 5.3.6
cc-remote update --version 5.3.6
```

Ordinary Wrapper updates preserve the independent Claude session service. In-process side chats and queued messages must finish before activation. The release includes six platform-specific Relay/Wrapper bundles, `install.sh` and `SHA256SUMS`, with no new Desktop or mobile installer.
