# cc-remote v5.2.1

## 中文

修复发送 Claude 新消息时，正文短暂闪出“重试加载详情”，随后才显示“正在处理”的问题。

前端现在仅在已确认的历史回合或已有历史摘要上自动读取详情。新消息等待实时输出，回复结束到会话空闲之间也不会误触发。刷新、切换设备和子代理续办时的历史恢复继续保留。

### 升级

通信协议保持 **v84**，Claude Agent SDK 保持 **0.2.157**。从 v5.2.0 升级无需协议迁移：

```sh
cc-remote update --check --version 5.2.1
cc-remote update --version 5.2.1
```

该修复随 Relay 的 Web 客户端发布，更新后刷新 Web/PWA 或重新打开 Desktop。其他设备可分别更新。从 v5.1.1 或更早版本升级仍需按 [v5.2.0 发布说明](https://github.com/muggle-stack/cc-remote/blob/v5.2.0/docs/releases/v5.2.0.md)协调迁移到协议 v84。

发布包含六个平台的 Relay/Wrapper 包、`install.sh` 和 `SHA256SUMS`，由 GitHub Actions 完成回归、平台导入检查和 attestation。没有新的 Desktop 或移动端安装包；发布本身不切换线上服务。

## English

Fix the brief “Retry loading details” message that appeared in a new Claude
reply before the normal processing UI.

Automatic detail reads now require a confirmed history turn or an existing
history summary. New turns wait for live output, including the interval between
reply completion and the session becoming idle. History restoration after
refresh, device switches and child-agent continuations remains available.

### Upgrade

Wire protocol remains **v84** and Claude Agent SDK remains **0.2.157**.
Upgrading from v5.2.0 does not require a protocol migration:

```sh
cc-remote update --check --version 5.2.1
cc-remote update --version 5.2.1
```

The fix ships in the Relay Web client. Refresh Web/PWA or reopen Desktop after
updating; other devices can update separately. Upgrades from v5.1.1 or earlier
still require the coordinated protocol v84 migration described in the
[v5.2.0 release notes](https://github.com/muggle-stack/cc-remote/blob/v5.2.0/docs/releases/v5.2.0.md).

The release includes six platform-specific Relay/Wrapper bundles, `install.sh`
and `SHA256SUMS`, with GitHub Actions regression tests, platform import checks
and attestation. It includes no new Desktop or mobile installer. Publishing does
not deploy services.
