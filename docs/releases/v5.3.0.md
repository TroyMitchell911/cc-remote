# cc-remote v5.3.0

## 中文

新增 Claude Code 回退功能：在历史用户消息旁点击“回退”，或输入 `/rewind` 选择消息，再确认恢复到发送这条消息之前。支持多轮历史中的位置以及第一条消息之前的空对话。

- 提供“恢复对话和文件”“仅恢复对话”“仅恢复文件”三个选项。长消息折叠后可展开，手机端保持圆角确认按钮可见。
- 检查原生能力和文件检查点，拒绝忙碌或已经过期的确认，避免重连后重复回退；对话与文件的部分成功会分别说明。
- 回退结果在刷新及其他客户端中保持一致。仅请求端会把原消息放回空白输入框，保留已有草稿；仅恢复文件不改变对话。

文件恢复使用 Claude Agent SDK 的公开 `rewind_files` 接口；对话恢复使用经过能力探测的原生 CLI 控制接口，并非公开的 Python SDK 方法。不支持的运行时会明确拒绝。文件检查点不覆盖任意 shell 操作，被记录文件后续的手工修改可能被覆盖。此功能限 Claude Code，Codex、DSH 与 Work 不显示回退入口。

### 升级

通信协议从 **v84 升到 v85**，Claude Agent SDK 保持 **0.2.157**。需要协调 Relay、所有 Wrapper 与 Web/PWA：完成依赖 Wrapper 进程的任务和排队请求，停止不兼容的旧 Wrapper，更新 Relay/Web，再更新各 Wrapper，最后刷新 Web/PWA 或重新打开 Desktop。

```sh
cc-remote update --check --version 5.3.0
cc-remote update --version 5.3.0 --allow-protocol-change
```

该开关表示已安排协议迁移，不会自动升级其他设备。独立 Claude 会话服务保留运行；私有 BTW、进程内会话和排队任务仍需先结束。参见[部署指南](https://github.com/muggle-stack/cc-remote/blob/v5.3.0/deploy/README.md)。

发布包含六个平台的 Relay/Wrapper 包、`install.sh` 和 `SHA256SUMS`，经过 GitHub Actions 回归、平台导入检查和 attestation。没有新的 Desktop 或移动端安装包；发布本身不切换线上服务。

## English

Add Claude Code rewind from a historical user message or `/rewind`. Select a message and confirm restoration to the point before it was sent, including older turns and the empty conversation before the first message.

- Choose conversation and files, conversation only, or files only. Long prompts expand within a bounded area; rounded confirmation buttons remain accessible on phones.
- Probe native capability and file checkpoints, reject busy or stale confirmations, and prevent duplicate mutations after reconnect. Report partial conversation/file results separately.
- Preserve the restored conversation across refresh and other clients. Only the requesting client prefills an empty draft; existing drafts remain intact. File-only restore leaves the conversation unchanged.

Files use the public Agent SDK `rewind_files` method. Conversation restore uses a capability-probed native CLI control, not a public Python SDK method; unsupported runtimes reject the operation. File checkpoints do not cover arbitrary shell effects and may overwrite later manual edits to tracked files. This feature is limited to Claude Code, excluding Codex, DSH and Work.

### Upgrade

Wire protocol advances from **v84 to v85**; Claude Agent SDK remains **0.2.157**. Coordinate Relay, all Wrappers and Web/PWA: finish Wrapper-owned work and queued requests, stop incompatible Wrappers, update Relay/Web, update each Wrapper, then reload Web/PWA or reopen Desktop.

Run `cc-remote update --check --version 5.3.0`, followed by
`cc-remote update --version 5.3.0 --allow-protocol-change` in an independent terminal. The flag acknowledges coordinated migration; it does not update other devices automatically. Independent Claude services remain running, while private BTW, in-process sessions and queued work must drain first. Follow the [deployment guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.0/deploy/README.md).

The release includes six platform-specific Relay/Wrapper bundles, `install.sh` and `SHA256SUMS`, with GitHub Actions regression tests, platform import checks and attestation. It includes no new Desktop or mobile installer. Publishing does not deploy services.
