# cc-remote v5.3.5

## 中文

修复居中和侧边图片文件预览无法双指缩放的问题。

- 支持电脑触控板、手机触屏双指放大／缩小，放大后可拖动查看。
- 切换居中与侧边布局时保留缩放比例；调整面板大小时约束图片位置，打开另一张图片时重置视图。
- 避免 Safari 同时发出多种手势事件时重复缩放。保留 SVG 安全处理、GIF 动画和图片解码错误提示。

通信协议保持 **v85**，Claude Agent SDK 保持 **0.2.174**。从 v5.3.4 升级无需协议或 SDK 迁移。更新 Relay 和各台 Wrapper 后刷新 Web/PWA 或重新打开 Desktop。

```sh
cc-remote update --check --version 5.3.5
cc-remote update --version 5.3.5
```

普通 Wrapper 更新保留独立 Claude 会话服务；仍在 Wrapper 内运行的侧聊及排队消息需先完成。发布包含六个平台的 Relay/Wrapper 包、`install.sh` 和 `SHA256SUMS`，没有新的 Desktop 或移动端安装包。

## English

Fix missing pinch zoom in centered and docked image file previews.

- Support trackpad and touchscreen pinch zoom, with panning while enlarged.
- Preserve zoom when switching presentation, constrain image position when resizing the panel, and reset the view for a different image.
- Avoid double zoom from overlapping Safari gesture streams. Preserve SVG sanitization, animated GIF playback, and image decode-error feedback.

Wire protocol remains **v85** and Claude Agent SDK remains **0.2.174**. Upgrading from v5.3.4 needs no protocol or SDK migration. Update the Relay and each Wrapper, then reload Web/PWA or reopen Desktop.

```sh
cc-remote update --check --version 5.3.5
cc-remote update --version 5.3.5
```

Ordinary Wrapper updates preserve the independent Claude session service. In-process side chats and queued messages must finish before activation. The release includes six platform-specific Relay/Wrapper bundles, `install.sh` and `SHA256SUMS`, with no new Desktop or mobile installer.
