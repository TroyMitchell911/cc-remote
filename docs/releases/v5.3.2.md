# cc-remote v5.3.2

## 中文

修复 Claude 刷新或重新打开会话后，文件列表全部显示“差异未保存”的问题。原生会话记录中已经保存的完整文件差异，现在可以在历史中正常查看。

- 从原生记录的正确位置读取 Edit/Write 差异，兼容结果中缺少文件路径的情况，并恢复连续多次编辑后的累计差异。
- 自动重建旧的 Claude 历史缓存，保留原生会话记录、图片等资源及其他引擎的缓存。
- 缺少原始证据、工具执行失败，或文件中途被 Bash 等未记录操作覆盖时，继续显示差异不可用；无法确定归属的批量结果也不会错误关联到某个文件。

### 升级

通信协议保持 **v85**，Claude Agent SDK 保持 **0.2.174**。从 v5.3.1 升级无需协议或 SDK 迁移。更新 Relay 和各台 Wrapper 后，刷新 Web/PWA 或重新打开 Desktop，重新读取历史即可恢复有完整记录的差异。

```sh
cc-remote update --check --version 5.3.2
cc-remote update --version 5.3.2
```

从 v5.3.0 或更早版本升级时，还需遵循 [v5.3.1 发布说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.1/docs/releases/v5.3.1.md)中的 SDK 服务升级要求，以及对应的协议迁移要求。普通 Wrapper 更新不会重启独立 Claude 会话服务。

发布包含六个平台的 Relay/Wrapper 包、`install.sh` 和 `SHA256SUMS`，由 GitHub Actions 完成回归、平台导入检查和 attestation。没有新的 Desktop 或移动端安装包；发布本身不切换线上服务。

## English

Fix Claude file lists incorrectly showing “Diff not saved” after refreshing or reopening a session. Complete file patches already stored in the native transcript are now available in historical turns.

- Read native Edit/Write patches from the transcript envelope, retain the tool's file path when the result omits it, and restore cumulative diffs across consecutive edits.
- Rebuild old Claude history caches while preserving native transcripts, binary assets and other engines' caches.
- Keep missing evidence, failed edits and patch chains broken by unrecorded operations such as Bash overwrites unavailable. Ambiguous batched results are not assigned to an arbitrary file.

### Upgrade

Wire protocol remains **v85** and Claude Agent SDK remains **0.2.174**. Upgrading from v5.3.1 needs no protocol or SDK migration. Update the Relay and each Wrapper, then reload Web/PWA or reopen Desktop. Reading history again restores diffs with complete native evidence.

```sh
cc-remote update --check --version 5.3.2
cc-remote update --version 5.3.2
```

Upgrades from v5.3.0 or earlier must also follow the SDK-service instructions in the [v5.3.1 notes](https://github.com/muggle-stack/cc-remote/blob/v5.3.1/docs/releases/v5.3.1.md) and any applicable protocol migration requirements. An ordinary Wrapper upgrade does not restart an independent Claude session service.

The release includes six platform-specific Relay/Wrapper bundles, `install.sh` and `SHA256SUMS`, with GitHub Actions regression tests, platform import checks and attestation. It includes no new Desktop or mobile installer. Publishing does not deploy services.
