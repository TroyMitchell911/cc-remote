# cc-remote v5.2.2

## 中文

修复多个 Claude 子代理连续完成时，返回链接挤到同一段回复、后续回复缺少对应链接的问题。

现在以主会话实际接收结果的时点关联返回链接；任务完成状态仍即时更新。历史记录会纠正旧实时数据和缓存里的链接位置、进度标题，刷新、切换会话及展开详情后仍保留正确归属。

### 升级

通信协议保持 **v84**，Claude Agent SDK 保持 **0.2.157**。从 v5.2.0 或 v5.2.1 升级无需协议迁移：

```sh
cc-remote update --check --version 5.2.2
cc-remote update --version 5.2.2
```

本次修复同时涉及 Wrapper 和 Relay 的 Web 客户端，请更新 Relay 及各台设备，随后刷新 Web/PWA 或重新打开 Desktop。升级保留独立 Claude 会话服务。从 v5.1.1 或更早版本升级仍需按 [v5.2.0 发布说明](https://github.com/muggle-stack/cc-remote/blob/v5.2.0/docs/releases/v5.2.0.md)协调迁移到协议 v84。

发布包含六个平台的 Relay/Wrapper 包、`install.sh` 和 `SHA256SUMS`，由 GitHub Actions 完成回归、平台导入检查和 attestation。没有新的 Desktop 或移动端安装包；发布本身不切换线上服务。

## English

Fix overlapping Claude child-agent returns placing several links above an earlier reply while leaving a later reply unattributed.

Return links now follow the main session's actual consumption of each result; task completion status still updates immediately. Canonical history corrects stale link positions and progress titles from older live/cache data, preserving attribution after refresh, session switches and detail expansion.

### Upgrade

Wire protocol remains **v84** and Claude Agent SDK remains **0.2.157**. Upgrading from v5.2.0 or v5.2.1 does not require a protocol migration:

```sh
cc-remote update --check --version 5.2.2
cc-remote update --version 5.2.2
```

This fix changes both the Wrapper and Relay Web client. Update the Relay and each device, then refresh Web/PWA or reopen Desktop. The independent Claude session service stays running. Upgrades from v5.1.1 or earlier still require the coordinated protocol v84 migration described in the [v5.2.0 release notes](https://github.com/muggle-stack/cc-remote/blob/v5.2.0/docs/releases/v5.2.0.md).

The release includes six platform-specific Relay/Wrapper bundles, `install.sh` and `SHA256SUMS`, with GitHub Actions regression tests, platform import checks and attestation. It includes no new Desktop or mobile installer. Publishing does not deploy services.
