# cc-remote v5.2.0

## 中文

v5.2.0 新增持久化 Claude 计划、完善权限同步，并支持在会话图片之间切换。通信协议从 **v83 升到 v84**，Claude Agent SDK 保持 **0.2.157**。

### 计划与权限

- 计划审批展示完整文档，并使用统一样式的权限选项选择批准后的执行模式；支持键盘操作和手机布局。
- 计划批准与任务完成分开显示。原生任务工具的成功结果更新进度，未完成的清单继续保留；只有计划正文、没有任务进度的计划仍可手动确认完成。
- “确认已完成”位于计划标题右侧。确认后各客户端同步收起，刷新、重连或重启后不会因为旧历史重新显示；计划正文仍保留在会话历史中。
- 原生进入或退出计划模式时同步真实权限。待处理工具授权不会因切换会话、旧回复结束或状态变为空闲而提前消失。
- 修复原生终端同步、TUI 计划读取、计划回放和会话回滚中的状态恢复。安装快照新增计划数据库与收起记录，兼容旧格式快照的原有恢复范围。

### 会话恢复与图片浏览

- 切换设备再返回时，恢复原回复结束后仍在继续执行的 Claude 内容。使用明确的原生归属读取最新详情，保留较新的实时输出和工具状态，不重新发送问题。
- 子代理返回链接在刷新、浏览器缓存和详情分页后保留，并继续打开对应子代理。
- 上传与生成的图片支持手机左右滑动、键盘和按钮切换；放大后可拖动查看。原图失败或超时时保留提示和重试入口，即使已有缩略图也能重试。

### 升级

**从 v5.1.1 或更早版本升级，需要协调 Relay、所有 Wrapper 和 Web/PWA 到协议 v84。** 先确认全部设备的升级窗口，完成依赖 Wrapper 进程的任务与排队请求，按[部署指南](https://github.com/muggle-stack/cc-remote/blob/v5.2.0/deploy/README.md)停止不兼容旧 Wrapper，升级 Relay/Web，再升级各 Wrapper，并刷新 Web/PWA。

在独立终端中检查并选择本版本：

```sh
cc-remote update --check --version 5.2.0
cc-remote update --version 5.2.0 --allow-protocol-change
```

这个开关表示已安排协议迁移，不会自动升级其他设备。首台设备可能需要既有 Relay 管理员的 `--relay-ssh` 配置；后续设备跳过已更新的 Relay。原有独立 Claude 服务不随 Wrapper 升级重启，私有 BTW、进程内会话和排队任务仍需先结束。完整步骤见[安装与升级](https://github.com/muggle-stack/cc-remote/blob/v5.2.0/docs/installation.md)。

发布包含六个平台的 Relay/Wrapper 包、`install.sh` 和 `SHA256SUMS`，由 GitHub Actions 完成回归、平台导入检查和 attestation。没有新的 Desktop 或移动端安装包；发布本身不切换线上服务。

## English

v5.2.0 adds persistent Claude plans, synchronized permissions and conversation
image navigation. Wire protocol advances from **v83 to v84**; Claude Agent SDK
remains **0.2.157**.

### Plans and permissions

- Show the full plan for approval with styled, keyboard-accessible choices for
  the execution mode after approval, including narrow mobile layouts.
- Separate approval from completion. Successful native task updates drive the
  checklist; unfinished steps retain the plan. Document-only plans retain manual
  completion.
- Place the completion button beside the plan heading. Dismissal synchronizes
  across clients and survives refresh, reconnect and restart; the document stays
  in conversation history.
- Mirror native permission changes. Keep pending tool approvals visible through
  session switches, parent-response completion and idle-state transitions until
  answered or explicitly closed.
- Recover canonical plans through native terminal mirroring, TUI reads, replay
  and conversation rollback. Activation snapshots include the plan database and
  dismissal receipts; older snapshot formats retain their original restore scope.

### Conversation recovery and images

- Restore Claude work continuing after a completed response when returning from
  another device. Load the exact native owner's latest detail, preserve newer
  live output and tool state, and never resend the prompt for recovery.
- Retain child-agent return links through refresh, browser caching and paged
  detail restoration, including navigation to the exact child.
- Navigate uploaded and generated images with mobile swipes, keyboard and
  buttons. Preserve panning while zoomed and show original-image errors and retry
  controls even when a cached thumbnail is available.

### Upgrade

**Upgrading from v5.1.1 or earlier requires a coordinated protocol v84 upgrade
of Relay, every Wrapper and Web/PWA.** Arrange the maintenance window, finish
Wrapper-owned work and queued requests, stop incompatible old Wrappers, update
Relay/Web, update all Wrappers, then reload Web/PWA. Follow the
[deployment guide](https://github.com/muggle-stack/cc-remote/blob/v5.2.0/deploy/README.md).

In an independent terminal, run `cc-remote update --check --version 5.2.0`, then
`cc-remote update --version 5.2.0 --allow-protocol-change`. This flag acknowledges
the coordinated migration; it does not update other devices automatically. The
first device may need the existing Relay administrator's `--relay-ssh` setting;
later devices skip the updated Relay. Independent Claude services remain running
during Wrapper upgrades; private BTW, in-process sessions and queued work must
finish first. See the
[installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.2.0/docs/installation_en.md).

The release includes six platform-specific Relay/Wrapper bundles, `install.sh`
and `SHA256SUMS`, with GitHub Actions regression tests, platform import checks
and attestation. It includes no new Desktop or mobile installer. Publishing does
not deploy services.
